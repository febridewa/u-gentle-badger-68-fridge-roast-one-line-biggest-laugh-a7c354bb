A make.fun entry for **Fridge Roast: One Line, Biggest Laugh** — one line, at most 200 characters, roasting a smart fridge. The roast is aimed at the fridge itself: its ice maker broke and its app answers with daily affirmations instead of ice.

Referral: `6etrfz79`

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes a single line of at most 200 characters to `/output/entry.txt`.
